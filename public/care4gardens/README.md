# Care4Gardens | MCC concept

A Dutch, responsive outdoor showroom concept for GitHub Pages. Buildless HTML, CSS and JavaScript; copied into the main Vite build through `public/`.

## Experience

- Cinematic muted hero with a photographic fallback; optional full introduction film with Arthur narration, music and photographic ending.
- Scroll-driven open/enclosed/evening scene, four matched before/after comparisons, and glass/screen/atmosphere controls.
- Searchable, filterable catalogue of 100 physical products, with the published variant combinations and prices from 25 October 2026. Original product images are hosted locally.
- Product detail dialog with precise variant selection and an outbound link to that variant in the existing Care4Gardens shop.
- Three-step garden brief. Downloading the brief stays local; the email button opens the visitor's own email client. Nothing is silently sent or stored.
- Reduced-motion support, motion pause, keyboard navigation, native dialogs, visible focus styles, semantic form labels, image alternatives and mobile layouts.

## Scope and provenance

This is a public MCC reference concept, not the official Care4Gardens website. Search indexing is disabled in the HTML and repository-level robots output. Generated lifestyle images are labelled as concept imagery and are not presented as completed customer projects. The catalogue uses a dated snapshot of the public `https://care4gardens.nl/products.json?limit=250` feed; the zero-price appointment and unrelated zero-price wall-tile listing are intentionally excluded. Douglas structures and pergolas use the bespoke quotation path.

Prices and availability must be reconfirmed in the existing shop. There is no live inventory, cart, payment gateway, backend enquiry submission or invented customer review. The colour/height/installation choices in product dialogs are the actual published variant options. Atmosphere interactions are illustrative photographic transitions, not an engineering configurator or insulation claim.

Assets: the ten user-approved generated before/after images and the approved introduction video from this conversation; product photography from the public Care4Gardens shop; locally hosted DM Sans and Playfair Display with their OFL licenses. Evening colour grading is an atmosphere illustration.

## Editing and publishing

Edit `index.html`, `collectie.html`, `styles.css`, `app.js`, or `catalogue.json`. All asset paths are relative and support a GitHub Pages project subdirectory. No application dependencies are needed for this folder.

The approved media is stored in integrity-checked archive parts under `media/care4gardens/`. Run `python3 scripts/care4gardens-assets.py` to restore the ignored `public/care4gardens/assets/` directory. The existing `npm run assets` command also runs this restoration automatically. This retains the exact images, videos, fonts and licenses without relying on expiring source links.

The 15-second muted `hero-loop.mp4` is tracked separately beside `index.html` for independent updates. The restoration script skips the superseded archived loop.

The parent repository's existing `Deploy MCC Prototypes` workflow builds and publishes all prototypes after a push to `main`. The parent portfolio index is generated by `scripts/finish.mjs`.

Before making this the official business website, connect live commerce and lead handling, approve company copy and pricing, and replace illustrative project evidence with customer-approved photography where appropriate.
